## ✨ Features

- **Interactive & Modern UI**: Built with custom CSS design tokens, smooth scroll behavior, and glassmorphism elements.
- **Custom Cursor & Canvas Animation**: Dynamic custom cursor ring with an interactive canvas background grid.
- **Fully Responsive**: Optimized for seamless viewing across desktop, tablet, and mobile devices.
- **Project Showcase**: Highlights live web applications, cybersecurity tools, e-commerce platforms, and ML projects.
- **Direct Contact Form**: Integrated contact form powered by FormSubmit.

## ⚡ Quick Start / Local Setup

To run this portfolio website locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/srijithit/sri.git
   cd sri
   ```

2. **Open in browser:**
   Simply open `index.html` in any web browser, or start a local live server:
   ```bash
   npx serve .
   ```
